# Code of conduct

OpenMVIS follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful and constructive in issues, pull requests, discussions
and any other project space. Harassment, personal attacks, discriminatory
remarks and publishing others' private information are not acceptable.

Reports go to **contact@openmvis.com**. The maintainer reads every report,
keeps the reporter's identity confidential and answers within a week. Actions
range from a private note to a permanent ban from the project's spaces,
following the Contributor Covenant's enforcement guidelines.
